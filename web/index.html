What it watches

VIGIL isn't a dashboard wearing a costume. Every action it takes is a real API call — PATCH for timeouts, DELETE for kicks, PUT for bans. When it says someone is timed out, Discord itself says so too.

🛡️ Moderation

Kick, ban, timeout, warn, purge — with role-hierarchy awareness. If the target outranks VIGIL, it refuses instead of failing red.

📜 Audit-first

Every action lands in an auto-created #mod-log: kicks, bans, timeouts, purges, even edits and deletes from other users.

🚨 Raid radar

Watches join velocity and raises the alarm the moment an account-burst looks like a raid — before the channels fill up.

💬 Human-native replies

Every reply is an ephemeral embed — only you see the confirmation, the chat stays clean for your members.

🔒 Permission-aware

Self-targeting, owner-targeting, and bot-targeting are all refused. The hierarchy check runs before every single action.

📁 No smoke and mirrors

No MongoDB, no webhooks, no external services. Warnings live in a local JSON file. Delete the folder and it's gone.

Command map

Sixteen slash commands, grouped by what they do.

commandwhat it does
/warnIssue a warning with a reason (ephemeral confirmation)
/warningsList a member's warning history
/remove-warningRetract a specific warning by ID
/clear-warningsWipe a member's warning slate
/timeoutTimeout a member for a human duration ("10s", "2h", "3d")
/kickKick a member
/banBan a member, optionally pruning their messages
/unbanReverse a ban by user ID
/purgeBulk-delete messages in a channel
/slowmodeSet channel slowmode to slow down spam
/lock · /unlockToggle channel send-permission lockdown
/modlogLocate (or create) the #mod-log channel
/raid-statusReport the current join-velocity posture
/helpThe command atlas, rendered as an embed
/pingLatency & gateway health
